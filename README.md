## 📌 Sobre este proyecto

Bienvenido a mi portafolio. Aquí encontrarás una **galería interactiva** con los proyectos y lenguajes que domino dentro del ecosistema Web y Datos.

Cuento con conocimientos sólidos en **HTML, CSS, SASS, JavaScript** y **bases de datos relacionales (SQL Server)**, aplicados al desarrollo de interfaces modernas, responsivas y funcionales.

## ⚙️ Instalación y ejecución local

Sigue estos pasos para ejecutar el proyecto en tu máquina:

**1. Clonar el repositorio**
```text
git clone https://github.com/KevinGo24/My_website.git
```

**2. Ingresar a la carpeta del proyecto**
```text
cd My_website
```

**3. Abrir el archivo `Index.html`**

Puedes abrirlo directamente en tu navegador o usar una extensión como *Live Server* en VS Code para una mejor experiencia de desarrollo.
